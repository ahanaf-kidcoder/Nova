# Nova
### A Modern C++ Library for Math, AI, Robotics & Research

<p align="center">
  <b>Build. Compute. Discover.</b>
  </p>

  Nova is a header-only, high-performance C++ library designed for researchers, engineers, and students working in mathematics, artificial intelligence, robotics, and scientific computing.

  ---

  ### ✨ Features

  | Domain | What you get |
  | --- | --- |
  | **Math** | Linear Algebra: Matrices, Vectors, Eigenvalues, Decompositions |
  | **AI / ML** | Neural Networks, Tensors, Optimizers, Loss Functions |
  | **Robotics** | Kinematics, Dynamics, Control Systems, Path Planning |
  | **Research** | Statistics, Optimization, Numerical Methods, Data Structures |

  - **Header-Only**: Just include and go. No complex builds.
  - **Modern C++20**: Clean APIs using templates and constexpr
  - **Fast**: Designed for performance with Eigen-like syntax
  - **Research First**: Built to prototype and publish papers fast
